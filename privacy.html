Privacy Policy

Effective date: October 12, 2026 · Operator: tesachikku · Application: auto_shorts_bot

This policy describes the personal, owner-operated auto_shorts_bot application and these informational pages. The bot operates only for channels explicitly authorized by its operator.

2. Processing and external providers

  • Google / YouTube: processes authorized API requests, uploaded media and publication metadata.
  • Google Gemini: receives public competitor titles and public performance metadata, original fictional scripts and stock-photo prompts for script generation and quality checking. The application does not send OAuth credentials or the connected channel’s private Analytics reports to Gemini. Gemini’s own terms and the configured project’s data-use settings apply; free-tier inputs may be used by Google to improve its products.
  • Pixabay: receives generic photo search terms and its API credential, and provides stock images with source information. It does not receive Google tokens or private channel reports.
  • GitHub Actions: executes the private automation workflow and stores configured secrets, workflow artifacts and a durable state branch. GitHub processes these according to its policies.
  • Kokoro / FFmpeg: speech synthesis and video assembly run in the execution environment. Model files may be downloaded from their distribution host; narration is not submitted to a hosted speech-generation service.

The operator does not sell Google user data or use it for targeted advertising. Google user data obtained through OAuth is not provided for training or improving generalized AI models. Public research inputs sent to an AI provider are distinguished from the connected channel’s private reports.

3. Storage, access and retention

OAuth credentials are generated on the operator’s computer and may then be saved as GitHub Actions secrets. They are not embedded in these webpages or committed to source code. Locally created credential files remain until the operator removes them.

Private workflow outputs, including generated media and channel reports, are retained as GitHub Actions artifacts for the configured 14-day period. Local copies remain until manually deleted. Public video observations in the durable state are pruned after 30 days when the bot runs. Upload history and scheduling records persist in the private shorts-state branch until the operator deletes or resets them.

Access is limited by the permissions on the operator’s computer, GitHub repository, secrets and Google project. Cloud providers may maintain logs and backups under their own policies. The application cannot promise that revocation or deletion instantly removes provider-controlled logs or backups.

4. Revocation and deletion

  1. Stop the scheduled workflow by setting AUTOPUBLISH=false or disabling the workflow.
  2. Revoke the application’s Google access from Google Account connections. This prevents further authorized access.
  3. Delete YOUTUBE_TOKEN_JSON and any local token.json / client_secret.json copies when no longer needed.
  4. Remove retained workflow artifacts, local output folders and application state records. Check existing channel videos before resetting upload history to avoid duplicates.
  5. Videos already uploaded to YouTube remain on the channel until the operator deletes them in YouTube Studio. Revoking OAuth does not delete published videos.

For questions or assistance with access, correction or deletion, use the operator’s User support email displayed on the Google OAuth consent screen for auto_shorts_bot.

5. Informational website

These three informational pages have no application login, data-entry form, advertising script or analytics script. The hosting provider, GitHub Pages, may process standard request information such as IP address, browser information and security logs under the GitHub Privacy Statement.

6. Google Limited Use

auto_shorts_bot’s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements. Google user data is used only to provide the disclosed application functionality. Access by the operator is limited to operating the personal application, reporting, support and security.

7. Updates and platform policies

Material changes to data processing will be reflected on this page before the new processing begins. Relevant provider policies include Google Privacy Policy, GitHub Privacy Statement and Pixabay Privacy Policy.
