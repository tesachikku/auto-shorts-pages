Application information

Original stories.
One connected workflow.

auto_shorts_bot is a personal YouTube Shorts production and scheduling utility run by its owner. It researches public video metadata, creates original fictional micro-stories, and uploads videos to the operator’s authorized channel.

영어 숏츠의 공개 지표를 조사하고, 독창적인 허구 스토리를 제작해 운영자 본인의 YouTube 채널에 예약 업로드하는 개인용 도구입니다.

01 / Research

Public video metadata

Compare recent video titles, publication dates and public statistics using the YouTube Data API. Metadata is a research sample, not a global ranking or access to other creators’ private analytics.

02 / Create

Original fictional Shorts

Generate a new English script, synthesize narration locally, and edit licensed atmospheric stock photos into a vertical video with captions. Competitors’ video files are not copied.

03 / Schedule

The operator’s own channel

Upload completed videos and schedule future publication after Google authorization. Read the connected channel’s performance reports for local review.

Google access, explained

The application requests read-only YouTube channel access, video upload permission, and read-only YouTube Analytics access. These permissions support channel identification, upload scheduling and performance reporting. It does not request Gmail, Google Drive, contacts, payment or account-password access.

Google sign-in takes place through Google’s authorization flow. This information website does not accept credentials or provide a public sign-in form. The bot runs in the operator’s local environment or private GitHub Actions repository.

Availability and support

This is an owner-operated personal utility, not a public subscription service. API access and platform availability determine whether a run can complete. The application does not guarantee views, revenue, monetization approval or Google verification.

For access or privacy questions, contact the operator using the User support email shown on the Google consent screen for auto_shorts_bot. This identifies the support contact configured for the OAuth application.
